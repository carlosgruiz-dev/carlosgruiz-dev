Entrevista Python Venezuela

Sep 21, 2018

Entrevista con Jesús Gómez del proyecto Python Venezuela sobre mis inicios como programador, Python y el proyecto en el que trabajo.

Jesús Gómez (@jgomo3) ha dado inicio a una serie de entrevistas a miembros de la comunidad de Python Venezuela, y bueno tuve la fortuna de ser su primer invitado. Durante una hora estuvimos hablando de mis inicios como programador, cómo conocí y adopté a Python y finalmente un poco sobre el proyecto en el que trabajo actualmente.

Entrevista a Carlos Gustavo Ruiz | Python Venezuela 2018

Si quieren saber más de la comunidad Python Venezuela, pueden visitar la página pyve.github.io/ o conversar en directo en el chat de Telegram.

Algunas tecnologías nombradas en la conversación fueron:

  • Lenguajes de programación: Python, Pascal, Basic y C.

  • Django y Flask como entornos de programación web.

  • Infraestructura de Datos Espaciales

  • PostgreSQL y PostGIS para bases de datos espaciales.

  • GeoNode como gestor de contenidos geográficos.

  • GeoServer para publicar servicios de mapas.

  • GeoNetwork para gestión de metadatos.

  • VIM, que es el editor de texto que utilizo.

Para ver las siguientes entrevistas pueden visitar el canal de youtube de la Fundación Python Venezuela
