Camelot

Jun 9, 2010

Sobre Camelot, un proyecto para GUIs en Python inspirado en Django, con la presentación de FOSDEM 2009.

Hace un año más o menos me enteré de la existencia del proyecto Camelot, un proyecto para GUIs inspirado en las funcionalidades de Django. Algo realmente ambicioso y por supuesto bienvenido para los programadores que como yo, habiendo conseguido un excelente Framework para la web, sentimos que faltaba en el mundo de las GUI.

Si bien no soy fanático de Qt, aunque reconozco el excelente trabajo que realizan, lo que promete este Framework (al menos en mi caso) es completar mi caja de herramientas en el área de las aplicaciones de entorno de ventanas. Les dejo la siguiente presentación y aplaudo la iniciativa y constancia del equipo de desarrollo. Pronto lo estaré bajando y dando mis primeros pinitos con este fabuloso programa.

FOSDEM 2009 Camelot

A modo de comentario final el link para el proyecto es: https://www.python-camelot.com/ y pueden instalar la versión estable desde pypi.
